## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/paswanthreddy6/ai-shopping-assistant.git
```

### 2. Open the Project

```bash
cd ai-shopping-assistant
```

### 3. Run the Website

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
